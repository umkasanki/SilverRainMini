# Silver Rain Mini 1.0 — техническое задание

Документ отвечает на вопрос «что именно сделать и как проверить, что сделано».
Почему решения такие — в [PLAN.md](PLAN.md). Внешний вид — макет из PLAN 6.2.

Порядок старшинства при расхождении: **макет → PLAN.md (журнал решений) → SPEC.md**.
Найденные расхождения внутри PLAN разобраны в разделе 9; если SPEC уточняет PLAN,
изменение вносится в журнал решений PLAN тем же коммитом.

Объём: **только версия 1.0 (этап 1 PLAN)**. Этапы 2 и 3 здесь упоминаются лишь
там, где 1.0 должна оставить для них место.

Составлено 17.10.2026.

## 2. Функциональные требования

Каждое требование имеет номер `FR-n` и критерии приёмки (КП). Критерии без
пометки проверяются вручную, с пометкой **[тест]** — автотестом.

### FR-1. Агент в панели меню
- Значка в Доке и в «Command-Tab» нет (`LSUIElement = YES`).
- При запуске в панели меню появляется значок станции (FR-2).
- Повторный запуск уже работающего приложения второго значка не создаёт.

КП: после `make run` в панели есть значок, в Доке — нет.

### FR-2. Значок в панели меню
Силуэт логотипа станции, 18 × 18 pt. Строится из того же SVG, что и обложка (раздел 5):
шаблонное изображение берёт только альфа-канал, поэтому силуэт получается из файла
логотипа без отдельной перерисовки.

| Состояние плеера | Вид |
|---|---|
| `idle` | шаблонное изображение, цвет подстраивает система |
| `connecting`, `reconnecting` | то же, плавная пульсация прозрачности 1,0 ↔ 0,35, период около 1,6 с |
| `playing` | силуэт залит `#FF3600` (не шаблон) |
| `error` | шаблонный силуэт + маленький значок `exclamationmark.circle.fill` в правом нижнем углу |

- Метка доступности: «Серебряный Дождь», значение — текущее состояние словами.
- При «Уменьшить движение» пульсация заменяется постоянной прозрачностью 0,5.

КП: все четыре вида видны в светлой и тёмной теме; в `playing` — оранжевый.

### FR-3. Открытие панели и меню
- **Левый клик** по значку открывает стеклянную панель (FR-6) под значком.
  Повторный левый клик, клик мимо панели или `Esc` закрывают её.
- **Правый клик** (и `Control`-клик) открывает меню из двух пунктов:
  **«Настройки…»** (`⌘,`) и **«Выйти»** (`⌘Q`), разделённых разделителем.
- «Настройки…» открывает окно настроек (FR-10) поверх остальных окон и делает
  приложение активным.

КП: каждый жест делает ровно своё; панель не остаётся висеть после клика мимо.

### FR-4. Воспроизведение и машина состояний

```swift
enum PlaybackState: Equatable {
    case idle
    case connecting
    case playing
    case reconnecting(attempt: Int)
    case error(PlaybackFailure)
}
```

Переходы — строго по схеме PLAN 5. Событие движка, которому в текущем состоянии
нет перехода, игнорируется с записью в лог: запоздалое «звук пошёл» после `stop()` —
штатная гонка, а не ошибка программиста.

| Событие | Из | В |
|---|---|---|
| `play()` | `idle`, `error` | `connecting` |
| элемент готов и звук пошёл (`timeControlStatus == .playing`) | `connecting`, `reconnecting` | `playing` |
| устранимый сбой (FR-5) | `connecting`, `playing`, `reconnecting` | `reconnecting(n)` |
| неустранимый сбой | `connecting`, `reconnecting`, `playing` | `error` |
| `stop()` | любое | `idle` |

- `pause` в смысле «запомнить место» не существует: и ⏸, и `stop()`
  уничтожают `AVPlayerItem`. Следующий ▶︎ создаёт новый элемент — живой эфир.
- Буфер: `automaticallyWaitsToMinimizeStalling = true`,
  `preferredForwardBufferDuration = 5`.
- Таймаут подключения: 15 с в `connecting` без звука → устранимый сбой.

КП **[тест]**: все переходы таблицы на фейковом движке; недопустимые переходы
не меняют состояние. Вручную: поток № 1 играет через ≤ 3 с после ▶︎.

### FR-5. Сбои и переподключение
**Классификация сбоев:**

| Неустранимые → `error` | Устранимые → `reconnecting` |
|---|---|
| неверный URL, не-HTTPS адрес | нет сети, таймаут, обрыв соединения, DNS |
| HTTP 4xx (403 приходит как ошибка формата — тоже неустранимо) | HTTP 5xx |
| формат не поддерживается `AVPlayer` | `AVPlayerItemPlaybackStalled` дольше 10 с |
| | таймаут подключения (FR-4) |

**Расписание повторов** (`ReconnectPolicy`): 2, 5, 10, 30, 30, 30… с, без
ограничения числа попыток. Счётчик сбрасывается при переходе в `playing`.

**Сеть** (`NetworkMonitor`, `NWPathMonitor`): когда путь становится `satisfied`
во время `reconnecting`, таймер отменяется и попытка делается сразу.

**Сон** (`SleepWatcher`, `NSWorkspace.willSleepNotification` / `didWakeNotification`):
- перед сном: если состояние не `idle` и не `error`, запомнить «играло» и `stop()`;
- после пробуждения: если «играло» — `play()`; сеть может ещё не подняться,
  это штатно разрулит `reconnecting`.

**Аварийный путь** (`PlaylistResolver`, PLAN 3):
- срабатывает **только для встроенных потоков**, не для «Своего адреса»;
- условие: сеть `satisfied`, а **три попытки подряд** к адресу из `streams.json`
  завершились сбоем, либо адрес дал неустранимый сбой;
- действие: загрузить `https://silver.ru/radio/48.m3u`, взять первую строку,
  похожую на URL, заменить схему `http` на `https`, играть этот адрес;
- в подзаголовке видно, что играет запасной поток (FR-7);
- на каждом следующем `play()` и при каждом новом цикле переподключения сначала
  пробуется основной адрес — запасной не «прилипает»;
- если не удался и плейлист → `error` «Не удалось подключиться».

КП **[тест]**: расписание задержек и сброс; разбор плейлиста (пустой, с
комментариями `#EXTM3U`, CRLF, `http`→`https`, мусор). Вручную: Wi-Fi выключен на
минуту → включён → играет само ≤ 3 с после появления сети; сон 5 мин → играет.

### FR-6. Стеклянная панель
Раскладка и вид — **строго по макету** (PLAN 6.2). Ширина 300 pt.

1. **Плашка «Сейчас играет»**: обложка 40 × 40 (логотип на полупрозрачной светлой
   подложке, скругление 11), заголовок «Серебряный Дождь», подзаголовок (FR-7),
   справа кнопка ▶︎/⏸ (`play.fill` / `pause.fill`). Во время `connecting` и
   `reconnecting` кнопка показывает ⏸ — нажатие останавливает попытки.
2. **Плашка «Звук»**: подпись «Звук», ползунок громкости (FR-8). Справа в строке
   ползунка в 1.0 ничего нет, но раскладка не должна сдвигаться, когда на этапе 2
   туда встанет кнопка AirPlay (ползунок — `frame(maxWidth: .infinity)` в `HStack`).
3. **Строка «Качество»** (только если включена настройка `showQuality`): `Menu`
   со списком потоков, отмеченный — текущий. Выбор = FR-9.
4. **Пилюля «Свернуть»** внизу, вне плашек: закрывает панель.

- Плашки: `.glassEffect(.regular, in: .rect(cornerRadius: 20))` внутри
  `GlassEffectContainer`. **Цвета фона не задаются нигде.**
- Все значки — SF Symbols.
- Клавиатура: `Tab` проходит ▶︎ → ползунок → качество → «Свернуть»; `Space` на ▶︎
  переключает воспроизведение.

КП: снимки панели в светлой и тёмной теме совпадают с артбордами макета
«1.0 светлая» и «1.0 тёмная» по составу, порядку и пропорциям.

### FR-7. Тексты состояния (подзаголовок плашки и Now Playing)

| Состояние | Подзаголовок |
|---|---|
| `idle` | «AAC 96» (короткое имя текущего потока) |
| `connecting` | «Подключение…» |
| `playing` | «В эфире · AAC 96» |
| `playing` на аварийном пути | «В эфире · запасной поток» |
| `reconnecting` | «Переподключение…» |
| `error` | «Не удалось подключиться» |

Короткое имя потока — поле `shortTitle` в `streams.json` («AAC 96», «MP3 128»,
«AAC 48»); для «Своего адреса» — «Свой адрес».

### FR-8. Громкость
- Громкость приложения (`AVPlayer.volume`, 0…1), системную не трогает.
- По умолчанию 100 %. Значение и признак «без звука» запоминаются между запусками.
- Ползунок — своя компонента `VolumeSlider`: капсула высотой 28 pt во всю ширину
  плашки, значок динамика внутри слева, заполненная часть светлая
  (осознанное отступление, PLAN 6.2).
- Ввод: перетаскивание; клик в точку ставит значение сразу; колёсико и тачпад
  (вертикальная и горизонтальная прокрутка); стрелки ←/→ и ↑/↓ — шаг 5 %.
- Клик по значку динамика — «без звука»; значок меняется на `speaker.slash.fill`,
  заполнение остаётся видимым приглушённым. Повторный клик или любое изменение
  громкости снимает «без звука».
- Значок динамика по уровню: `speaker.fill`, `speaker.wave.1.fill`,
  `speaker.wave.2.fill`, `speaker.wave.3.fill`.
- Доступность: элемент «Громкость», значение в процентах, `accessibilityAdjustableAction`.

КП: громкость меняется плавно, без щелчков; переживает перезапуск; «без звука»
работает и снимается.

### FR-9. Каталог потоков и смена качества
- `Resources/streams.json`, встроен в бандл:

```json
[
  { "id": "aac96",  "title": "Высокое · AAC 96",  "shortTitle": "AAC 96",  "url": "https://silverrain.hostingradio.ru/silver64.aac",  "default": true },
  { "id": "mp3128", "title": "Стандарт · MP3 128", "shortTitle": "MP3 128", "url": "https://silverrain.hostingradio.ru/silver128.mp3" },
  { "id": "aac48",  "title": "Эконом · AAC 48",   "shortTitle": "AAC 48",  "url": "https://silverrain.hostingradio.ru/silver48.aac" }
]
```

- Модель называется `RadioStream` (имя `Stream` занято `Foundation.Stream`).
- Ровно один поток помечен `default`; каталог без него или с битым JSON —
  ошибка сборки на уровне теста, а не падение в работе.
- Выбор хранится в `streamId`; значение `custom` означает «Свой адрес».
- Неизвестный сохранённый `streamId` → поток по умолчанию.
- Смена потока во время игры: новый `AVPlayerItem`, пауза ≤ 2 с, состояние
  проходит через `connecting`. В `idle` — только запоминается.

КП **[тест]**: загрузка каталога; поток по умолчанию; неизвестный id; свой адрес
пустой, без схемы, `http://`, корректный.

### FR-10. Окно настроек
Сцена `Settings`, одна вкладка, `Form` + `.formStyle(.grouped)`. Размеры и
выравнивание руками не задаются.

| Секция | Элемент | Тип | Хранение | По умолчанию |
|---|---|---|---|---|
| Основные | Запускать при входе в систему | `Toggle` | `SMAppService` | выкл |
| Основные | Включать радио при запуске | `Toggle` | `playOnLaunch` | **вкл** |
| Поток | Поток | `Picker`: 3 потока + «Свой адрес…» | `streamId` | `aac96` |
| Поток | Адрес (виден только при «Свой адрес…») | `TextField` + кнопка «Проверить» | `customURL` | пусто |
| Поток | Показывать качество в панели | `Toggle` | `showQuality` | выкл |
| — | Версия | текст из `Info.plist` | — | — |

**Автозагрузка** (`LoginItem`, PLAN 8.4): переключатель показывает реальный
`SMAppService.mainApp.status`, перечитывает его при каждом открытии окна. При
`.requiresApproval` — подпись «Разрешите в Системных настройках → Объекты входа»
и кнопка «Открыть настройки», вызывающая `SMAppService.openSystemSettingsLoginItems()`.

**«Проверить»** (`StreamProbe`): GET с таймаутом 5 с, читаются только заголовки,
соединение закрывается. Результат под полем: «AAC · 96 kbps» (из `Content-Type` и
`icy-br`), либо «Нужен адрес https://», либо текст ошибки.

**Включать радио при запуске:** если включено, при старте приложения сразу
вызывается `play()`. Вместе с автозагрузкой это и есть «включил Mac — слушаешь».
Сеть при входе в систему может ещё не подняться — это штатно разрулит FR-5.

КП: окно неотличимо по виду от Системных настроек; автозагрузка переживает
перезагрузку; выключение её в Системных настройках отражается в переключателе.

### FR-11. Интеграция с системой (Now Playing)
- `MPNowPlayingInfoCenter`: заголовок «Серебряный Дождь», исполнитель — подзаголовок
  из FR-7, обложка — логотип 600 × 600 (рисуется из SVG в рантайме),
  `MPNowPlayingInfoPropertyIsLiveStream = true`.
- `playbackState`: `playing` → `.playing`; `connecting`/`reconnecting` → `.playing`
  (пользователь хочет звук); `idle` → `.stopped`; `error` → `.stopped`.
- `MPRemoteCommandCenter`: `play`, `pause`, `togglePlayPause`, `stop` включены;
  `pause` = `stop()` (живой эфир). Перемотка, «следующий» и «предыдущий» выключены.

КП: плитка в Пункте управления показывает «Серебряный Дождь · В эфире · AAC 96»;
F8 и кнопки AirPods переключают воспроизведение.

### FR-12. Выход
«Выйти» в меню по правому клику: `stop()`, снятие Now Playing, сохранение
настроек (`UserDefaults` синхронизируется сам), `NSApp.terminate`.

### 4.2 Ключевые технические решения

| Вопрос | Решение | Причина |
|---|---|---|
| Значок и панель | **`NSStatusItem` + своя `NSPanel`**, а не `MenuBarExtra` | у `MenuBarExtra` нет способа отличить правый клик от левого, а меню по правому клику утверждено (PLAN 6.6). Тот же путь PLAN 13 называет запасным для Liquid Glass. **Отступление от «стандартного API» — записать в журнал** |
| Содержимое панели | SwiftUI `PanelView` в `NSHostingView` | весь интерфейс остаётся на SwiftUI и системном стекле |
| Настройки | сцена `Settings` + `openSettings` | стандартный путь. Если из агента с `NSStatusItem` окно не открывается надёжно — своё `NSWindow` с тем же `SettingsView`; решается на шаге S1 |
| Плеер | `AVPlayer` за протоколом `PlaybackEngine` | машину состояний можно тестировать на фейке без сети |
| Время | `ReconnectPolicy` и таймеры получают `Clock` извне | тесты без реальных задержек |
| Состояние | `@Observable @MainActor final class AppState` | Swift 6, без Combine |
| Concurrency | UI, плеер и мосты — `@MainActor`; сеть — `async`/`await` | строгая проверка |
| Настройки | `UserDefaults` через `@AppStorage`, ключи — в одном `enum SettingsKey` | одно место для имён ключей |

### 4.3 Хранимые настройки

| Ключ | Тип | По умолчанию |
|---|---|---|
| `streamId` | String | `aac96` |
| `customURL` | String | `""` |
| `showQuality` | Bool | `false` |
| `playOnLaunch` | Bool | `true` |
| `volume` | Double | `1.0` |
| `isMuted` | Bool | `false` |

Автозагрузка в `UserDefaults` не хранится — её держит система. Признак
«играло до сна» живёт только в памяти.

### 4.4 Сборка

`project.yml` описывает две цели: приложение `SilverRainMini` и тесты
`SilverRainMiniTests`. Версия `1.0`, сборка `1`.

```
make app      # xcodegen generate && xcodebuild ... -configuration Release → build/Silver Rain Mini.app
make run      # make app && open "build/Silver Rain Mini.app"
make test     # xcodegen generate && xcodebuild test
make install  # копирует в /Applications (нужно для стабильной автозагрузки)
make clean
```

### 4.5 Цикл разработки
Разработка идёт прямо на Mac: сборка, запуск, логи
(`log stream --predicate 'subsystem == "local.oleg.SilverRainMini"'`) и снимки
экрана делаются на месте. Схема PLAN 11 «WSL → push → pull на Mac» больше не нужна.
